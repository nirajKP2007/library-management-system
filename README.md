# 📚 Library Management System

A simple Java-based Library Management System built using `ArrayList`. This project allows users to manage books in a library by adding, borrowing, returning, removing, and viewing available books.

## ✨ Features

- Add books to the library
- Prevent duplicate books from being added
- Borrow books
- Return borrowed books
- Remove books from the library
- Display all available books
- Track issued books

## 🛠️ Technologies Used

- Java
- ArrayList
